# StudyMate AI

A Qubators Lesson 6 local prototype.

## Files
- `PRD.md` — product requirements, implementation phases, technology decisions and agent/design notes.
- `design.html` — design preview required by Task 2.
- `index.html` — initial working local application page required by Task 3.

## Run locally
Open `index.html` directly in a browser.

## Scope
This is an assessment prototype using mock/test data. It does not include production authentication, deployment, API keys or private credentials.

## Assessment alignment
- Task 1: implementation phases and technology/agent decision are documented in `PRD.md`.
- Task 2: visual design preview is in `design.html`; refinement is documented in `PRD.md`.
- Task 3: working single-page prototype is in `index.html`.
